\section*{Five date formats}

The package default is the US format. The other four formats can be selected
as package options, through \verb|\kbset|, or for one board as shown here.

\dateformatboard{us}{US: MM/DD/YYYY}
\hfill
\dateformatboard{english}{English: DD/MM/YYYY}

\bigskip

\dateformatboard{german}{German: DD.MM.YYYY}
\hfill
\dateformatboard{iso}{ISO: YYYY-MM-DD}

\bigskip

\dateformatboard{ymd}{Year first: YYYY/MM/DD}
